What changed in this consolidation

  • The live market scan was returning nothing, and now returns markets. On 2026-11-21 the demo exchange’s newest open page was almost entirely KXMVECROSSCATEGORY combo markets, so /markets?status=open&limit=1000 matched 0 of the five topics. The scan now applies the documented mve_filter=exclude and then one request per topic series (series_ticker=…), with the series list generated from the committed collection — desk/data/series-index.json, built by desk/tools/build_series_index.py. Two of those series were re-fetched to confirm they return real topic markets; the regression check is desk/tools/dom_test.mjs section 7.
  • The nightly engine refresh was failing, and the cause is fixed. A market matched by title text can arrive with no series_ticker, and the candle path is /series/{series}/markets/{ticker}/candlesticks — the missing key raised TypeError: quote_from_bytes() expected bytes. Such markets are now skipped and logged, the refresh excludes combo markets, it fans out over the same series list, and it exits non-zero when it genuinely collects nothing instead of pretending to succeed.
  • The desk CI failure was a Node version mismatch. jsdom 31 needs Node ≥ 22; desk.yml pinned Node 20, so the DOM-test step failed and blocked the commit of refreshed desk data. Both desk workflows now use Node 22.
  • The landing page names one canonical page per job. The six parallel ≥ $0.10 builds are no longer presented as a choice for the reader: the trade desk is canonical and the rest are indexed on archive/index.html, still live, nothing deleted. Marked as a consolidation decision in COORDINATION.md.
