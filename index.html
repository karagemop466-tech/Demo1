Kalshi demo dashboard

Five topics — gas prices, elections, culture, crypto and golf — on the Kalshi demo exchange. One desk to watch every contract move of $0.10 or more, chart price against time and order-book depth, follow each event until it resolves YES or NO, and grade simulated trades.

Demo exchange; no credentials used. Kalshi's demo environment uses mock funds, and its prices may not reflect real markets ↗. This site uses public endpoints only: no API key is stored, no order is ever sent, and every authenticated account/portfolio figure is left blank rather than estimated. Do not paste a private key into this public page — see SEC-01, AUTH-01, KEY-01 and FILL-01.

Start here — the trader desk

These four pages are the working path. They share one set of modules in trade-desk/, poll the official demo API directly from your browser, and are covered by 82 automated checks (node trade-desk/tests/*.test.mjs). Start on the dashboard, click any market to load it into the chart and the order book.

1Trader desk Two scrolling chats side by side — Feed A every ≥ $0.10 move across the five topics, Feed B the subset the published fee-aware screen rates high ROI. Plus the ranked event board, a 15-minute movers table, the price chart, the order book and the resolution watch. 2Chart & depth Contract price on the y axis, time on the x axis, with seconds / minutes / hours windows. Under it, the order book: how many contracts are bid or offered at each price, YES and NO, with the spread. Kalshi returns bids only — the opposite side is implied, as the official docs explain. 3Resolutions Every watched event followed until the API returns a result — yes or no — with the settlement fields, the result source and the price path. Markets that vanish from the open list stay under watch until a result is observed. 4Paper trades Automated simulated trades: entry, official taker fee, $1-per-contract settlement at the market's own YES/NO result, then results grouped by topic, side, price band and strategy. Browser-local, except where a committed ledger is shown.

Several desks solve the same requirement. The ≥ $0.10 dual-chat rule, the price chart and the resolution watch were each built more than once by sessions running in parallel against one brief. Nothing was deleted: the trader desk above is the designated working path, and the page directory lists every implementation with its own description, so you can compare or ignore them. Each desk measures a “move” against a different price (best ask, last print, candle close), so a flag on one desk need not appear on another in the same minute. The consolidation map compares them field by field.
Ranking is an estimate. Kalshi's public API has no official dollar-volume field, so “24h $ (est.)” and dollar-ranked boards are computed as contracts × price and labelled as estimates wherever they appear. Where a last trade is absent, no value is shown rather than a guess. Definitions and the bounded scan they come from are on Executive summary and RANK-01.

Official sources

  • API environments ↗ — demo REST base https://external-api.demo.kalshi.co/trade-api/v2; production is a different host.
  • Demo environment ↗ — mock funds; prices and behavior may not reflect real markets.
  • GET /markets ↗ — market list, status filter and pagination.
  • Order book responses ↗ — bids only; the opposite side is implied at 1 − price.
  • Market settlement ↗ — YES/NO result and $1 per contract payout.
  • WebSocket quick start ↗ — the demo handshake requires a signed request, which is why this public site polls REST instead of holding a key.
  • GitHub Pages ↗ — this site is served as static files from the repository.
