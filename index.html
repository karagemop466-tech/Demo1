What changed in this consolidation round

  • The live scan was returning nothing; it now returns markets. On 2026-11-21 the demo exchange's newest open page was almost entirely KXMVECROSSCATEGORY combos, so /markets?status=open&limit=1000 matched 0 of the five topics. desk/live.html now applies the documented mve_filter=exclude plus one series_ticker request per series, from the generated list desk/data/series-index.json (desk/tools/build_series_index.py, 28 series over 5 topics). Regression: desk/tools/dom_test.mjs §7.
  • The scheduled engine refresh was failing; the cause is fixed. A market matched by title text can arrive with no series_ticker, and the candle path is /series/{series}/markets/{ticker}/candlesticks, so quote(None) raised TypeError: quote_from_bytes() expected bytes. The refresh now resolves the series from the official Get Event response, leaves candles empty with the reason when no series exists, excludes combos, and exits non-zero when it collects nothing.
  • The desk CI failure was a Node version mismatch. jsdom 31 needs Node ≥ 22; desk.yml pinned Node 20, so the DOM-test step failed and blocked the commit of refreshed desk data. Now Node 22.
  • The landing page names one canonical page per job instead of asking the reader to choose a survivor; the superseded pages are indexed on archive/index.html and remain online.

Scope: this dashboard uses the Kalshi demo Trade API for public market data and keeps dated snapshots for review. It is not a recommendation to trade. No authenticated account was connected and no exchange order was placed by this integration.
