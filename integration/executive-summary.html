Kalshi Demo Market Desk

This repository now has a curated GitHub Pages landing page, a direct-to-demo live market dashboard, five source-linked topic snapshot pages, a resolution view, a price-jump scanner, simulated-strategy tooling, and review registers. A separate consolidated desk built by another session is linked from the landing page; this integration does not change its implementation, and its requirements matrix and review register document that surface. This summary distinguishes verified API capabilities from this project’s estimates, bounded scans, and credential-dependent features.

Demo only: Kalshi’s demo environment uses mock funds, and demo prices and behavior may not reflect real markets. Public market-data endpoints are separate from authenticated account and order endpoints. Official demo environment warning ↗

Important limits and next actions

  1. Use demo-only data. Official documentation warns that demo market prices and behavior may not reflect production. Review Kalshi’s warning ↗
  2. Do not enter a private key in the public site. The experimental page currently stores one in browser local storage; the integration audit records this and asks for a protected server-side design. SEC-01 ↗
  3. Review known code issues before relying on analytics. The simulated YES close-P&L calculation (PAPER-01) and the jump scanner’s empty-result refresh path (JUMP-01) are flagged with code evidence. Open Flagged for Review ↗
  4. Mocked tests are not a live API check. After the integration rebase, node --test tests/dashboard.test.mjs passed all 46 assertions; an earlier fixture mismatch was not reproducible. The suite mocks network responses, so its pass does not verify current live exchange availability. See the test record in TEST-01.
  5. Interpret results within their scope. The live scanner uses a bounded set and heuristic topic matching; the snapshot pages are historical to their recorded collection time.
  6. Check sources per row. Market tables link to the official response/schema used; absent or unconfirmed data stays blank. The build’s snapshot generator and link audit are part of the deployment checks.
