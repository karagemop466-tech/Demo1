Trader's Guide — how to use this dashboard

One page that maps the whole site: which desk does which job, what every number means, and where each fact comes from. Written by session 91fc2cc7, 2026-11-20. Every row carries a source link; unconfirmed values are blank or flagged, never inferred.

This site tracks five topics on the Kalshi demo exchange — gas prices, elections, culture, crypto, golf — via the official Trade API. Demo is a test exchange with mock funds; its prices and liquidity may not reflect real markets. Source: docs.kalshi.com — Test In The Demo Environment (fetched 2026-11-20).
Never paste a private API key into any page of this public site. The site needs no key: market data is public. Portfolio and order placement need signed requests, and those cells are left blank rather than faked. See SEC-01 on the Flagged for Review page.

1 · The 60-second tour

  1. Scan the five topics live → open the primary live desk. It polls the official demo API directly in your browser and ranks events by dollar activity.
  2. Pick a market and read the chart → same page: price over time with a seconds / minutes / hours x-axis, plus the order-book ladder (contracts available at each price).
  3. Check what just moved → the jump scanner (≥ $0.10) lists sharp moves with a news-search lead per jump. A lead is a hint, not a proven cause.
  4. Test your idea with paper money → the simulated-trading desk runs rule-based strategies on the live trades tape with the official fee formula; nothing is sent to the exchange.
  5. Follow it to resolution → the resolution page and every desk's Resolution column show the final result (yes / no — scalar is also possible) returned by the API.

3 · How to read the numbers

Every fact below was re-read from the official Kalshi documentation and fee schedule on 2026-11-20 (links per row). If a value could not be confirmed from an official source, it is flagged instead of filled in.

FactWhat it means for youOfficial source
Contract pricePrices run $0.01–$0.99. A YES at $0.60 = market-implied 60% chance. YES and NO sum to $1.00. Market settlement docs (binary payout at $1); orderbook docs (reciprocal relationship).
Settlement pays $1YES outcome → $1 per YES contract; NO outcome → $1 per NO contract; only net positions settle. No settlement fee for simple yes/no. docs.kalshi.com/getting_started/market_settlement
Order book shows bids onlyThe API returns yes_dollars / no_dollars bid ladders as [price, count] pairs, ascending, best bid last. The ask is implied: a NO bid at $0.30 = a YES ask at $0.70. Spread = implied ask − best bid. An empty or unknown book returns HTTP 200 with empty arrays — not an error. docs.kalshi.com/getting_started/orderbook_responses
Chart resolutionOfficial candlesticks exist only at 1-minute, 60-minute and 1440-minute (1-day) intervals. "Seconds" views on this site are client-sampled quotes collected in your browser, clearly labelled — there is no official sub-minute series. candlestick API reference (period_interval = 1, 60, 1440); seconds-view disclosure on the live desk.
Market lifecycleinitialized → active → closed → determined → finalized (with inactive, disputed, amended states). REST filters: unopened / open / paused / closed / settled. After close, all order operations are rejected. docs.kalshi.com/getting_started/market_lifecycle
Resolution resultThe API sets result to yes, no — or scalar for range markets. The brief's "yes or no" framing is incomplete; desks render scalar as-is rather than forcing YES/NO. market lifecycle docs (determination and settlement section).
Trading feesTaker fee = round up(M × 0.07 × C × P × (1−P)) where P = price in dollars, C = contracts, M = multiplier (default 1). Example from the schedule's own table: 100 contracts at $0.50 → $1.75 fee. Maker fee = round up(M × 0.0175 × C × P × (1−P)) with M default 0 — so no maker fee unless the series is listed. No settlement or membership fee. Fee schedule "Last updated and effective: July 7, 2026". kalshi.com fee schedule PDF (fetched 2026-11-20).
Rate limitsToken-bucket based; most requests cost 10 tokens against Read/Write buckets that refill per second. Unauthenticated requests have separate limits that Kalshi does not publish — the desks throttle themselves and back off on 429. docs.kalshi.com/getting_started/rate_limits ("Unauthenticated requests" section).
Demo endpointsRecommended REST root https://external-api.demo.kalshi.co/trade-api/v2 (alt demo-api.kalshi.co); WebSocket wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2. Public market data needs no key; portfolio and orders need signed requests. Credentials are not shared between demo and production. demo environment docs; API environments.
"Highest dollar amount" is computed, not officialThe API publishes no dollar-volume field. Desks rank by volume × price (e.g. 24h $ volume = volume_24h_fp × last_price_dollars) and label it as an estimate. Definitions differ slightly per desk — disclosed on each page. exec-desk UNVERIFIED-04; RANK-01 on the Flagged page.
last_price $0.00 trapIn the collected demo snapshot, 1,471 of the 2,117 settled markets (69.5%) record last_price $0.00 — including 141 that resolved YES. It means "no trade recorded", not a fillable price; backtests that use it as an entry silently buy at zero. The engine excludes those rows and counts them. Re-derived this session from snapshot/resolved.json; methodology on engine/README.md.

5 · A ten-minute decision workflow

  1. Orient (1 min): open the live desk and keep the landing page open for the verified snapshot counts.
  2. Find the money (2 min): rank by 24h $ volume within one topic (keep topics separate; each topic page groups its markets — site/index.html). Remember the ranking is computed and labelled (UNVERIFIED-04).
  3. Read the book (2 min): best bid, implied ask = 1 − opposite best bid, spread, depth within ±5¢ — contracts available at each price, straight from the official bids-only book (docs).
  4. Check context (2 min): open the jump feed for ≥ $0.10 moves on that market; follow the news-search lead if one exists, and treat it as a lead only.
  5. Size the trade honestly (1 min): expected P&L must clear the official taker fee 0.07 × C × P × (1−P) (fee schedule). The simulated desks already apply this formula.
  6. Rehearse, then track (2 min): paper-trade the idea on the sim desk, then follow the market to resolution on the resolution page — the API returns result yes / no / scalar and settlement pays $1 per winning contract (docs).
