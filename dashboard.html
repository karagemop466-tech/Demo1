Minutes and hours use Kalshi candlesticks (1-minute and 1-hour periods). Seconds are built in this browser from a snapshot every 5 seconds, so they only cover the time since you opened the page. Kalshi candlesticks cannot be shorter than 1 minute.

Marked sharp moves are consecutive price changes of ≥ $0.10 in either direction. Each marker links to the market's official Kalshi page and the exact API request that produced the price; Kalshi does not report a cause, so no cause is asserted.
