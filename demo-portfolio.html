Local data boundary

Paper trades are stored in this browser's local storage and do not sync to Kalshi or another device. Clearing browser storage removes them. Each order uses a fresh public demo order-book snapshot and links to its source.

Actual account access

What remains unavailable

  • An authenticated demo balance, actual portfolio value, positions, and fills.
  • A server-side signer configured with demo-only credentials; this static site must never store a private signing key.
  • Written order authorization, a risk limit, and a verified fee/accounting policy before any actual API order is enabled.
Not a trading recommendation

Paper results are hypothetical, local to this browser, and based on a point-in-time visible book. The dashboard does not claim the simulation predicts execution or performance. See Flagged for Review and Suggestions.
