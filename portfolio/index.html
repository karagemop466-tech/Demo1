Connect a Kalshi demo account from this browser

Paste a demo API key id and its private key. The key is imported into the browser's Web Crypto API, used to sign each request locally, and held in sessionStorage only — it disappears when this tab closes and is never uploaded anywhere.

Demo credentials are separate from production credentials and are not shared between the two environments (demo environment ↗). Demo funds are mock money (source ↗).
