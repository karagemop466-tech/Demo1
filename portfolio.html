Demo portfolio

This page does not invent account values, trades, returns, or outcomes. All account-specific fields remain blank until authenticated demo responses are available.

Portfolio and order execution are not connected.

Kalshi documents that private API calls use an API key ID and a signature from the corresponding private key. A GitHub Pages client has no secure server-side signing boundary, and no demo account credentials or signing service were provided. No credential entry or browser-side private-key storage has been added, and this site has not submitted any orders. Read Kalshi's API key security guide.
