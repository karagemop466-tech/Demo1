Method & verification

  • Evidence generator: ops-desk/tools/build_health.py (stdlib only, unauthenticated) — re-run to refresh ops-desk/data/health.json. CORS probe: ops-desk/tools/cors_probe.py.
  • Official trigger semantics (schedule delays/drops under load, default-branch-only, minimum 5-minute interval): docs.github.com — Events that trigger workflows (schedule).
  • Official run-evidence endpoints (usable without authentication for public resources): docs.github.com — REST API endpoints for workflow runs.
  • Observed cross-origin behaviour for the browser re-check: committed header probe ops-desk/data/cors-probe.json (observed evidence, not a docs citation).
  • Verification performed for this page: schema + boot tests in ops-desk/test_ops_desk.mjs; repository link checker (node tools/check-links.mjs); Python syntax checks. Every table row carries a link to its official source.
