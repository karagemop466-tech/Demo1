Strategy lab

The brief asks for strategies “based on the type of trade”. Each one below is written as a machine-checkable rule over API fields, with the fee model applied, so a candidate is either supported by the data or it is not.

Ground rule used everywhere on this page

A strategy counts as measurable now only if every field in its entry rule exists in the captured payload. Anything needing a private feed, a news source, or an order book we cannot see is marked blocked with the blocker named — not quietly scored.

What would make these testable for real

  1. A stored ledger with labels. Fills alone give price/quantity/side. Intent has to be written at order time.
  2. Snapshot-before-order. Record the top of book and the depth ladder at the instant of submission; otherwise slippage can never be attributed.
  3. A reference feed for the settlement input. The 15-minute crypto rules settle on the average of the sixty seconds of CF Benchmarks BRTI before expiry — quoting Coinbase instead is a different number and a wrong model. That text is in the captured rules_secondary.
  4. A production comparison. Demo volume is a fraction of real volume; edges measured here do not transfer (see S-6).
  5. A minimum sample. Twenty legs cannot rank strategies. Treat every number here as a specification of the test, not a result.
