Suggestions

A review queue, not a changelog. Each item states the gap, the smallest action that closes it, what it unblocks, and the official source. Mark it approve, defer or reject below — the decision and your note stay in this browser, and “Export decisions” produces a JSON file to commit or paste into COORDINATION.md. Nothing here has been implemented.

How to review these. Four items are architecture- or trust-determining (S-1, S-2, S-5, S-6); the rest are quality-of-decision work. A deferral is a legitimate answer — it says “the current behaviour is acceptable for now”, which is different from silence. Items marked high impact that you reject should get a one-line note, because the code will keep behaving the flagged way and the next reader deserves to know that was deliberate.

If everything is approved, in what order

  1. S-10, S-8 — process and honesty guards first; they cost nothing and prevent the rest from producing confident-looking noise.
  2. S-5, S-4 — risk rail and labelling, both before any order exists.
  3. S-6, S-3 — reconcile the catalog, then use KXBTC15M as the fast test bench.
  4. S-2 — the proxy; the only item that needs infrastructure and your key.
  5. S-7, S-9 — scheduled refresh and resolution alerting, which turn a snapshot into a tracker.
  6. S-1 — exact turnover last, because it is the most expensive and the least likely to change a decision.

What this project will not do without an approval

  • No order will be placed, amended or cancelled by a page of this site. The signing tool exists; the call does not happen on load (guardrails).
  • No private key, token or credential will be committed, or accepted into page code or localStorage.
  • No number will be filled in from memory to complete a table; blanks and badges stay until a source resolves them.
  • No strategy will be reported as tested. The equity curve on the portfolio page is a replay of captured candles, labelled as such.
  • The five-topic filter stays exactly gas prices · elections · culture · crypto · golf, even where that means an empty column.

Decisions already taken outside this queue so the record is complete

  • Taking trades is deferred, not rejected — blocked on Q-1/Q-2, with the full specification and simulator already in place so approval is a configuration change plus one guarded run.
  • The dollar-volume proxy is adopted provisionally for ranking, and every affected header says “estimate”, with partial sums printed as a floor.
  • The seconds view ships as labelled 60-second buckets rather than being dropped or faked, with the REST limitation stated on the markets page.
  • Flagged items do not block publishing. They are on Flagged for review, linked from each table that they touch.
