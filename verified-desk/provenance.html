Method and its one unusual constraint

The sandbox where this work ran has no network route to Kalshi. Direct calls from the shell to the demo host fail at the TLS layer (three attempts, all curl exit 35), because only a short list of package and Git hosts is reachable. Live data was therefore retrieved through the agent's page-fetch tool, which returned real JSON from external-api.demo.kalshi.co. Consequences, stated plainly:

  • Large responses arrive in ~15 KB chunks; where a listing continued past the first chunk, only what was read is reproduced here, and the event's row count reflects that. That is what left one golf volume field empty (see FL-8).
  • No sandbox script could reach the API, so tools/refresh_snapshot.py has been run only for its failure paths: --check and --dry-run both report “the demo host was unreachable from this machine” and write nothing, which is the behaviour that matters when a capture dies mid-run. Its request shapes are the ones logged below, all plain unauthenticated GETs, so a machine with egress should reproduce them. tools/check_links.py runs fully offline and passes.
  • No HTTP response headers were observable, which is why CORS behaviour and rate-limit headers are open questions rather than findings.

Transcription rule applied: API field → same-named key in data/snapshot.json, value copied verbatim (strings kept as strings). Empty API strings stay ""; fields not present in the captured text become null. The only computed values on the site are labelled in the table headers or carry a floor/estimate badge, and the formula is printed next to them.

Reproduce or refresh

From any machine with internet access:

python3 tools/refresh_snapshot.py \
  --base https://external-api.demo.kalshi.co/trade-api/v2 \
  --out data/snapshot.json --check
node --test tests/kalshi.test.mjs
python3 tools/check_links.py

The refresher writes the same schema, records its own request log, keeps null for anything the API omits, and refuses to invent fields. --check re-verifies the two things that break silently: /series pagination behaviour and the tags→null case.

Integrity checks that run automatically

  • Every event and series row carries a source URL matching the demo host.
  • Market rows may only use field names the API actually returns — an invented key fails the test suite.
  • Nulls are preserved as nulls; the ranking marks a partial total as a floor.
  • The fee model must reproduce the published table; the URL builder must reject millisecond timestamps and >5,000-period ranges.
  • The base list must keep the exact hosts from the brief, and the “not exercised” flag on the un-probed hosts.
