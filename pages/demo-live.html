Price movement

Seconds view = polled official market snapshots every 3 s (Kalshi candlesticks minimum is 1 minute). Minutes = 1-minute candlesticks; hours = 1-hour candlesticks. When a candle has no trades, the closing best bid is plotted and labeled as such.

Liquidity — contracts available at each price

Pick “Book” on any market row. The official order-book endpoint returns resting YES and NO bids; YES asks are derived as 1 − NO bid (per official orderbook docs). $ depth = Σ(price × contracts), computed.

Where each number comes from

  • Live mode: GET {base}/markets?event_ticker=…&limit=1000, GET {base}/markets/{ticker}, GET {base}/markets/{ticker}/orderbook, GET {base}/series/{series}/markets/{ticker}/candlesticks — all documented at Quick Start: Market Data; demo base URL listed at API Environments.
  • CORS: published-site origin verified allowed by the demo API (repo file data/cors.json, checked 2026-11-20 from a GitHub Actions runner with an Origin header).
  • Snapshot fallback: data/demo-snapshot.json — verbatim API responses captured 2026-11-20 with per-record source URLs; verification log at docs/demo-data-verification.md.
  • Simulated trading & strategy analytics: Paper trading (SIM) — clearly labeled simulation; no real orders are possible without authenticated demo-account credentials.
Not investment advice. LIVE values come straight from the official demo API in your browser; otherwise the page shows only the verified snapshot. Empty cells mean “not returned”, never zero.
