Information we do have

  • Official demo REST base URL: https://external-api.demo.kalshi.co/trade-api/v2 (also supported: https://demo-api.kalshi.co/trade-api/v2).
  • Official demo WebSocket URL: wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2 (also supported: wss://demo-api.kalshi.co/trade-api/ws/v2).
  • Public market data (events, markets, order books, trades, candlesticks) needs no API key.
  • Portfolio, orders, trading, and WebSocket need a signed Ed25519/RSA demo API key.
  • Demo uses mock funds; no real money at risk.
