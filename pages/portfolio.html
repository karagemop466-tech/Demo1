Demo-account portfolio tracking

Tracks the Kalshi demo account (mock funds — no real money). Portfolio reads require an authenticated demo API key: KALSHI-ACCESS-KEY, KALSHI-ACCESS-TIMESTAMP, KALSHI-ACCESS-SIGNATURE (Ed25519/RSA signature of timestamp + method + path). No credentials are stored in this repository, so all values below are blank and flagged.
