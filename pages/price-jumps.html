Sharp price moves — jumps ≥ $0.10 in either direction

Scans the five tracked topics (gas prices, elections, culture, crypto, golf) for contract-price jumps of at least $0.10 between consecutive official candlestick closes. Every row links the official candlestick API request that produced it and the official venue event page. The Kalshi API has no field identifying what caused a move, so "possible cause" website links are left blank and flagged (F-17) — the venue event page is linked because it may display related-news digests. In LIVE mode the page reads the official Kalshi demo API directly; if that fails it falls back to the verified snapshot captured 2026-11-20 and says so. Nothing is ever invented.
