Event resolution tracker

A tracked event is polled with GET /markets?event_ticker=…. A market counts as resolved only when the API returns result = "yes" or "no" — the official enum for that field. Everything else (empty string, scalar, statuses active/closed/determined) is reported as not yet resolved. First-observed resolutions and their source URLs are stored locally so the history survives page reloads; nothing here is back-filled or estimated.

Why tracking is browser-local

  • GitHub Pages serves static files only — there is no server here to own a database.
  • Storing every user's watch list centrally would need a backend plus a privacy policy; that decision is listed on the suggestions board.
  • Export below produces a JSON file you can review, keep, or hand to an analyst; it is the same content shown in the tables.
