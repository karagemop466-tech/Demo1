Kalshi event-contract price graph

Tracks contract price over time (X-axis = time, Y-axis = current contract price in cents, 0–100). Window length is selectable in seconds, minutes, or hours. The liquidity table shows how many contracts are available at each price from the order book.

This graph is a simulation unless explicitly connected. Kalshi documents public REST market-data requests that do not require API keys. Use the Public REST monitor for real demo market snapshots and a session-only sampled price chart (subject to browser/network access). The separate authenticated WebSocket ticker feed is not connected here; no credentials are collected. The "Show simulated example" button draws clearly labeled fake data only to demonstrate the graph controls — it is not real Kalshi data. Sources: public market-data guide and WebSocket guide.

How to connect live (for your review)

// 1. Public market data — no key needed
fetch('https://external-api.demo.kalshi.co/trade-api/v2/markets/{ticker}')
  .then(r => r.json())

// 2. Live price stream — requires signed demo API key (WebSocket)
// wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2
// Subscribe: { "id": 1, "cmd": "subscribe", "params": { "channels": ["ticker"], "market_tickers": ["{ticker}"] } }
// Docs: https://docs.kalshi.com/getting_started/demo_env
