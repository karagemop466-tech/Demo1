Portfolio performance (demo account)

Not connected yet — and this is the only thing standing between you and a working portfolio page. A read-only worker is already written and tested: tools/account_worker.py. Give it a demo key (two environment variables) and it writes data/account.json; this page then renders real balances, realised P&L, fees and fill statistics automatically on the next build. It never places orders. Setup is documented in Sources and on Questions (Q1).
Why there are no numbers here. Every portfolio endpoint requires signed requests (KALSHI-ACCESS-KEY, KALSHI-ACCESS-TIMESTAMP, KALSHI-ACCESS-SIGNATURE — see Quick Start: Authenticated Requests). This repository has no key and the build environment holds none, and a public static site must never hold one: anything shipped to the browser is public. Inventing demo balances would be fabrication, so the page shows the exact endpoints, fields and formulas instead. The single decision needed to unblock it is Question Q1.

How performance is measured once a key is connected

Equity

Cash from balance_dollars plus mark-to-market of open positions. Mark value uses the position's market_exposure_dollars, not a hand-typed price.

Realised P&L

realized_pnl_dollars per market from Get Positions, reconciled against settlement payouts from Get Settlements. Fees come from fees_paid_dollars and each fill's fee_cost.

Execution quality

Per fill: intended price vs yes_price_dollars, is_taker flag, and the depth that existed at that price in the order book at the time.

Denominator discipline

Win rate and average return are reported with the number of closed trades. Below a disclosed minimum sample, the dashboard says “insufficient sample” instead of showing a misleading percentage.

Rate limit note carried over from the docs

Balance has its own rate-limit bucket (1 request/second on lower tiers) and the documentation advises reacting to fill events rather than polling. That shapes the design: a small server-side worker signs requests and caches results, and the browser reads only cached JSON.
