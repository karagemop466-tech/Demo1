Verification method

  1. Documentation pages fetched from docs.kalshi.com and quoted in the collector's docstring.
  2. Data collected by tools/collect_kalshi.py on a GitHub Actions runner with unrestricted egress.
  3. Every JSON record stores the request URL that produced it; the site renders that URL as the row's source.
  4. Absent fields render as “—” and are listed on Flagged for review.
  5. The build fails if any internal link is broken.
