Kalshi demo research overview

What this is

A live research dashboard for the Kalshi demo exchange, focused on gas prices, elections, culture, crypto and golf. Market prices, order-book depth and resolution outcomes are read straight from the official Trade API v2 demo endpoints by a scheduled job, and every row keeps a link to the exact API request that produced it.

Executive summary

  • Data is real and official, but demo. All figures come from , the recommended demo base URL documented at docs.kalshi.com. The demo exchange is a test venue — values are not real-money liquidity.
  • Scope. Only five topics are tracked. Topic membership is decided by an explicit, published keyword/category rule set, listed on each topic page so its accuracy can be audited.
  • Resolution tracking. Markets are followed until settled; the API's result field (yes / no) and settlement value are recorded with the resolution source from the event.
  • “Highest dollar amount” is measured, not assumed. Contract volume is not dollars. Dollar notional is computed as the sum of yes_price_dollars × count_fp over the last 24 hours of public trades, and the record count behind every total is shown.
  • Portfolio, trade analysis and order execution are credential-gated. No Kalshi API key exists in this repository or in the build environment, so those pages document the exact endpoints and payment logic instead of inventing figures. This is listed as a blocker on Flagged for review.
