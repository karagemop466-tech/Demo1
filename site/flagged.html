IrregularityWhat the site showsWhy it happensOfficial sourceStatus
Demo exchange values are not production valuesEvery price, depth level and volume figure comes from external-api.demo.kalshi.co.The demo environment is Kalshi's test venue with separate credentials and books.docs ↗By design — disclosed in the footer and every table
No portfolio, fills or settlement dataThe portfolio page shows endpoints and methodology but no figures.No Kalshi demo API key exists in the repo or environment; a static site cannot hold one.docs ↗Blocked on the user (Q1)
No trades executedNo order has been submitted; the order form is documentation only.Execution needs a signed server-side service and explicit risk limits.docs ↗Blocked on the user (Q2)
“Highest dollar amount” is an interpretationRanking uses a computed 24 h traded notional with the trade count shown.The brief does not define the metric; alternatives are listed in Q3.docs ↗Needs a definition

Fee-adjusted edge is not shownSpreads are labelled pre-fee.The fee formula has not been verified against the official fee schedule in this session.docs ↗Needs verification (Q6)
Charts are bucketed, not tick-levelCandlesticks use the documented 1 / 60 / 1440-minute intervals.Sub-minute history requires the authenticated WebSocket stream.docs ↗Design limit
