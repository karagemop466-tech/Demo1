Verification rule

Data provenance

What each live source link means

The event table links to the official API's event lookup filtered by event ticker, including nested markets. Market and order-book links point to a ticker-specific demo resource. These JSON URLs are the source of the displayed values, not a cached snapshot stored in the repository.

Method note

What “visible bid notional” means

For every returned YES and NO bid level, the site multiplies the official price-in-dollars string by its fixed-point contract quantity, then sums those products across currently open nested markets. It assigns a ranking value only when all open markets in that event have valid snapshots. It does not convert volume contracts to dollars or use the deprecated liquidity field.
