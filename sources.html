C · Data provenance at runtime

  • All market numbers (prices, volume, open interest, liquidity, orderbook depth, results) come live from external-api.demo.kalshi.co/trade-api/v2 (or its documented alternate demo-api.kalshi.co on failure — switch logged in the UI).
  • Every table row carries a Source link to the exact official API query that produced it.
  • Values the API does not return are shown as blank “—” with a flag; they are never inferred.
  • Portfolio fills/fees/balances are SIMULATED and labeled; fee math uses fact S-8.
  • Local persistence (localStorage) holds only: discovery cache (10 min), price samples, and the SIM portfolio — clearly separable from API data.
