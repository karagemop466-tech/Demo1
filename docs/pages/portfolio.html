How to enable (no manual data entry anywhere else)

  1. Create a demo account at demo.kalshi.co ↗, then under Account & security → API Keys create a key (per the official quick start ↗).
  2. Add repository secrets KALSHI_DEMO_API_KEY_ID and KALSHI_DEMO_PRIVATE_KEY (PEM). The private key never enters the site or this chat.
  3. Run python3 scripts/demo_trader.py status (portfolio read) — or dispatch a CI workflow that runs it; docs/data/portfolio.json refreshes and this page lights up.
  4. Trading additionally requires KALSHI_ALLOW_TRADING=1; orders go to POST /portfolio/events/orders (official Create Order V2 ↗; legacy write endpoints return 410 Gone).
