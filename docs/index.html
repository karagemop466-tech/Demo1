Kalshi demo — executive data hub

Collects, organizes and analyzes live market data from the official Kalshi demo Trade API for five topics only: gas prices, elections, culture, crypto, golf. Data is fetched on a schedule by CI from external-api.demo.kalshi.co/trade-api/v2 and published as static JSON; every table row links to the official API response or documentation behind it. Unverified values are left blank and flagged — nothing is inferred.

Executive summary — key findings

Environment
DEMO
Recommended REST external-api.demo.kalshi.co/trade-api/v2; WebSocket external-api-ws.demo.kalshi.co/trade-api/ws/v2 — verified against official environments page ↗.
Public market data
No auth
Events, markets, order books, candlesticks, trades are public (official quick start ↗); portfolio/trading require signed API keys.
Demo vs real
Thin books
Demo markets use mock funds; most show near-zero volume (verified live 2026-11-20). Rankings still work — but treat demo dollar figures as test data only.
Resolution
YES / NO
Settled markets expose result + settlement_ts + settlement_value_dollars (verified live: e.g. KXAAAGASMIN-26DEC31-3.80 → yes, $1.00).
Price history
Candles
Official candlesticks endpoint, 1 min / 1 hour / 1 day intervals (docs ↗) — wired into the live dashboard.
Trading
V2 orders
POST /portfolio/events/orders with bid|ask, fixed-point strings; legacy write endpoints are removed (410 Gone) — docs ↗. Credential-gated scaffold in scripts/demo_trader.py.
