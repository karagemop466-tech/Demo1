Sources

Everything on this desk is derived from the documents below or from responses returned by the official Kalshi demo Trade API. Each entry records what it was used to verify. Where a claim could not be checked against one of these, it is blank on the site and listed on Flagged.

Official documentation

SourceWhat it establishes hereRead
API environments and endpoints Demo REST base https://external-api.demo.kalshi.co/trade-api/v2 is the recommended demo host; demo WebSocket wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2; signed path is host-independent.2026-11-20
Demo environment Demo is a test exchange with separate credentials; the values here are not real-market prices.2026-11-20
Get Markets Market fields used everywhere: status, result, yes_bid_dollars, yes_ask_dollars, last_price_dollars, volume_24h_fp, close_time, settlement_value_dollars; status= filter values; 1,000-row page limit.2026-11-20
Get Events series_ticker (topic lookup) and settlement_sources (the venue's own determination sources, linked on each alert).2026-11-20
Get Trades The trades tape: the only public source with sub-minute trade timestamps, so every jump and every seconds-window chart point comes from here. min_ts/max_ts are in seconds.2026-11-20
Orderbook responses Bids only; a YES ask at X is a NO bid at 1−X with the same size; levels are [price_dollars, count_fp], ascending, best bid last.2026-11-20
Get Market Orderbook depth parameter bounds (0–100); an unknown ticker returns 200 with empty arrays, never 404.2026-11-20
Get Market Candlesticks Only 1, 60 and 1440-minute periods exist; at most 5,000 periods per request; start_ts/end_ts in seconds. This is why the seconds chart uses trades.2026-11-20
Market lifecycle Real status values are initialized / active / inactive / closed / determined / disputed / amended / finalized; result can be yes, no or scalar.2026-11-20
Market settlement YES holders get $1 per contract on YES, NO holders $1 on NO; only net positions settle.2026-11-20
Fee schedule (PDF) Taker fee ceil(M × 0.07 × C × P × (1−P)), maker 0.0175, no settlement fee, and the 21-row general fee table the implementation is asserted against.2026-11-20
Rate limits Unauthenticated public requests have separate limits and clients must back off on 429. api.js enforces a minimum gap, one in-flight request per URL, and exponential backoff.2026-11-20
WebSocket quick start WebSocket connections require a signed handshake bearing KALSHI-ACCESS-KEY / -SIGNATURE / -TIMESTAMP, even for public channels. A public static page cannot hold a key, so this desk polls REST instead.2026-11-20
API keys Signed requests need an API key id and an RSA private key; no key exists in this repository or in the browser.2026-11-20

What is deliberately not cited. No cause is ever attributed to a price move. The desk links the venue's own settlement sources and a news search; a search result is a lead for a human to check, not evidence of cause. Any such claim would be exactly the kind of inference this site refuses to make.
