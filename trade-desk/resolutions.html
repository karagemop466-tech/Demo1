Every market you follow is polled until Kalshi returns a settlement result. The tracker shows the exact field values the API returned (status, result, settlement_ts, settlement_value_dollars) and links each observation to the request that produced it. Some markets are scalar, which is why the YES/NO framing is shown as a column and never forced.
