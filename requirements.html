Executive brief · verified docs / open account inputs

A read-only market monitor is feasible; portfolio trading is not safely connectable from this repo alone.

The site uses Kalshi's recommended demo Trade API endpoints for public market data, filters the five requested topics, ranks complete live order-book snapshots by calculated visible bid notional, charts prices, and stores a local watchlist through explicit YES/NO outcomes. It does not fabricate market or account values.

What is verified

Executive summary

  • Kalshi documents distinct production and demo REST/WebSocket endpoints; demo credentials do not work against production.
  • Public market-data calls can be made without authentication. The demo docs caution that demo prices and behavior may not reflect real markets.
  • Current order books provide YES and NO bid price levels and contract quantities. This site computes price × contracts for each visible bid level and sums those values for a transparent ranking metric.
  • Kalshi market records expose price, contract volume, open interest, status, and a result field. A YES/NO outcome is displayed only when the API returns it.
  • Authenticated account balance, positions, fills, and orders require signed access. A secure server-side signer and demo account authorization are not present.

Important boundary

GitHub Pages serves static files and cannot keep a Kalshi private signing key secret. No API key or private key was supplied, and this site does not request one or store one in the browser. Real account performance and actual Kalshi order submission are blocked; a separate browser-local paper simulator is available and is not an account connection. See Portfolio & paper orders and Flagged for review.

Nothing in this dashboard is a trade recommendation or a promise of liquidity.
