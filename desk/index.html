Kalshi demo desk

One source-linked dashboard for the five requested topics — gas prices, elections, culture, crypto and golf. It ranks events by dollars traded, follows each market until the exchange returns a YES or NO result, and runs a recorded simulation of eight trading strategies against the official demo API. Nothing on this site is estimated: every figure links to the API request that produced it, and every gap is listed on Flagged for review.

Read this first. The Kalshi demo environment is a test exchange with mock funds, and Kalshi states that its prices and behaviour “may not be reflective of those in real markets” (official page). Dollar figures below are demo-venue numbers; they show that the dashboard works, not what a real account would earn.

Honest limits of this page

  • Demo venue. All prices, depths and results are from Kalshi's demo exchange, not production.
  • Dollar ranking is a computed proxy. Kalshi has no “highest dollar amount” field; the desk ranks by measured 24 h traded notional where trades were measured and falls back to 24 h contract volume otherwise, labelling which basis each row used.
  • Coverage is bounded. The committed snapshot covers the top series by volume per topic, not the entire exchange: 1,399 open markets and 4,430 closed ones.
  • Paper trading, not execution. No order left this repository.

Data: official Kalshi demo Trade API https://external-api.demo.kalshi.co/trade-api/v2 · endpoint documentation docs.kalshi.com. Values in the tables are the exchange's own numbers; anything the API does not return is left blank and listed on the Flagged for review page.
