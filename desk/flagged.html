A static GitHub Pages site cannot hold a secret: anyone can read the JavaScript, and a committed key is a leaked key.↗ sourceAdd the demo key as repository Actions secrets and run a read-only job that writes a JSON snapshot (the repo already has tools/account_worker.py as a starting point).

FL-03“Highest dollar amount” is not an API fielddisclosed proxyKalshi's market object has contract counts, not traded dollars. The desk computes 24 h traded notional as Σ(price × contracts) from public trades where it measures them, and labels the fallback (24 h contracts) per row.↗ sourceTreat the ranking as “most traded by dollars”, not as an official liquidity measure.

FL-08Sub-minute history is not available from RESTconstraintCandlesticks support 1, 60 and 1440 minute intervals only. FL-09Some markets quote a $0.00 yes ask or a $1.00 no askdata quirkWhen the opposite side of the book is empty, the exchange can report a 0.00 ask. Those rows cannot be bought at that price. The desk excludes them from strategy entry and does not compute a spread from them.↗ sourceRead the book endpoint before trading a one-sided quote.
FL-10Long-dated markets will not grade for monthssampling limitMany tracked markets close in 2027-2029. Paper trades on them stay OPEN and are excluded from win rate and ROI until the exchange resolves them.↗ sourceNothing to fix; sample size grows automatically as short-dated markets settle.

What this desk does not do

  • It does not place orders, hold keys, or read an account.
  • It does not claim any price move was caused by a news story.
  • It does not extrapolate, interpolate or back-fill a missing value — a blank stays blank.
  • It does not treat a closed-but-undetermined market as a NO.

Data: official Kalshi demo Trade API https://external-api.demo.kalshi.co/trade-api/v2 · endpoint documentation docs.kalshi.com. Values in the tables are the exchange's own numbers; anything the API does not return is left blank and listed on the Flagged for review page.
