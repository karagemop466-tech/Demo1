Sources

Every behavioural claim on this site traces to one of these official documents. They were read on 2026-11-20; the quote column paraphrases the specific sentence the implementation depends on so a reviewer can check it in one click.

The live demo API answered the collection runs that produced desk/data/ and snapshot/; each row in every table carries the exact request URL that returned its numbers, so a value can be re-fetched and compared.
