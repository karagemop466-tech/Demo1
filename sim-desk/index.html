Sim-Desk — automated simulated strategy runner

SIMULATED FILLS — no orders placed Kalshi DEMO environment official public API data only runs unattended on CI every 30 min
What this is. A rule-based strategy engine runs unattended on GitHub Actions every 30 minutes. Each run reads the official Kalshi demo Trade API (public endpoints, no keys), ranks open markets in the five tracked topics (gas prices, elections, culture, crypto, golf) by computed 24h traded notional, evaluates three disclosed strategies against the official public trades tape (GET /markets/trades; the demo candlesticks endpoint currently returns empty arrays for most markets — a flagged demo irregularity) and the official bids-only orderbook, and simulates fills (entry = implied best ask; fee = official taker formula). Open positions are carried across runs, marked to market, and settled automatically with the official $1-per-contract rule when the market resolves YES or NO. The append-only ledger is committed back to this repository, so this page is fully static and reproducible. Every number below traces to a committed JSON file and the official request URL that produced it.

    Methodology (deterministic, disclosed)

    1. Universe and "highest dollar amount" ranking

    Open markets are listed from GET /markets?status=open&limit=1000 (official limit ≤ 1000). Topic classification uses the transparent keyword rules in sim-desk/config.json (first rule wins; matched-by recorded per trade). Candidates need ≥ 100 contracts traded in 24h and ≥ 2h until close, and are ranked by computed 24h traded notional = volume_24h × last_price_dollars — a disclosed estimate, because Kalshi publishes no official dollar-volume field. Top 20 candidates (≤ 6 per topic) get signals evaluated.

    2. Strategies

    momentum-1h — buy YES when the 6-hour trend of official 60-min closes is ≥ +$0.05, buy NO at ≤ −$0.05 (entry band $0.30–$0.85). mean-revert-24h — fade moves ≥ $0.10 away from the mean of available hourly closes (entry band $0.10–$0.60). longshot-value — buy NO when its implied ask ≤ $0.20 on markets with ≥ 5,000 contracts traded in 24h. Priority: momentum → mean-revert → longshot; one position per market+side; max 15 open, 4 per topic, 3 new trades per run, 10 contracts per trade.

    3. Fill, fee, mark, settlement

    Fill price = implied best ask of the bought side (official reciprocal rule: a NO bid at Y is a YES ask at $1−Y). Fee = official taker fee roundup(M × 0.07 × C × P × (1−P)), M = 1. Open positions are marked each run to the official last_price_dollars (held side). When the market reports status=settled and result ∈ {yes, no}, the held side is paid $1.00 per contract if it matches the result, else $0.00 — the official settlement rule; settlement fee is zero for simple yes/no determinations.
