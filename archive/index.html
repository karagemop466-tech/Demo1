Sessions worked on this brief in parallel and several of them built the same feature. Why two pages can disagree

The six ≥ $0.10 implementations share the threshold but not the measured price: one compares best asks, one last prints, one candle closes, one book mid-points. A flag on one page therefore need not appear on another in the same minute, and that is a property of the inputs, not an error. The canonical trade desk labels the basis on every bubble so the reader can tell which one they are looking at.

Rules this page follows

  • Nothing deleted. Superseded pages stay at their published URLs; this index only points at them.
  • No invented data. The table above holds page names and one-line descriptions taken from each page’s own text, no market values.
  • One owner per figure. Where two pages show the same market, the canonical page is the one whose row links the API request; anything unconfirmable is blank and listed on Flagged for review.
  • Shared files. Per COORDINATION.md, the landing page, the navigation and the shared table data are changed only by the integration session, which is the session that built this index.

Official references behind the canonical pages

  • GET /markets ↗: series_ticker and mve_filter (only / exclude), the two filters the live scan uses.
  • GET /markets/{ticker}/orderbook ↗: contracts resting at each price.
  • GET candlesticks ↗: period_interval 1, 60 or 1440 minutes — there is no seconds resolution, which is why seconds charts are built from the tape a page observes itself.
  • Demo environment ↗: mock funds, prices may not reflect real markets.
