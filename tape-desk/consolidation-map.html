What the numbers imply (findings, not actions taken)

  1. The same requirement is served many times. The two ≥ $0.10 alert-chat feeds alone are implemented in 8 folders (alert-desk, alerts, trade-desk, exec-desk, live-desk, monitor, pages, plus this desk). Each is a complete implementation with its own data path; none of them is wrong, but a trader has to choose, and the landing page asks them to.
  2. Recommendation: one hub, three verbs. Keep one page per verb — watch (topic board + chart + ladder), react (the two chats), review (resolutions, portfolio, strategy results) — and turn the other desks into links with a one-line description. This desk publishes its data as data/watchlist.json so consolidation can consume it instead of re-collecting it.
  3. Do not delete a folder from this page. Every folder here was claimed by a session on the board; pruning is an integration action and belongs on the board, not in a generated table.
  4. Snapshot age is the real liveness limit. The committed snapshot this site renders is refreshed by the repository's own workflows; a page that only reads committed files is a snapshot page. Real-time means the browser talking to the demo API — which is what this desk does, and why its status badge says SNAPSHOT ONLY when it cannot.
