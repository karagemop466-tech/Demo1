00 / CONNECT DEMO ACCOUNT

One-time connection — demo API key (Ed25519 or RSA)

Connect

Your key signs each request inside your browser (WebCrypto). It is sent only to external-api.demo.kalshi.co — never to this site, GitHub, or anywhere else. Nothing is stored server-side; with “remember” off, the key lives only for this tab session.

How to create a demo API key (official steps)

  1. Create / open your demo account at demo.kalshi.co ↗ (mock funds; credentials not shared with production — official demo docs ↗).
  2. Account & security → API Keys → Create Key (official API-keys guide ↗).
  3. Save the private key PEM (shown once) and the key ID; paste both here.
  4. This is the only manual step on this site — keys are secrets and cannot be created by an agent (flagged in Flagged for review).

Signed-request spec verified from official docs: headers KALSHI-ACCESS-KEY/TIMESTAMP/SIGNATURE; signature = base64(Ed25519 or RSA-PSS-SHA256 over timestampMs + METHOD + path-without-query); timestamp tolerance ±30 s. Source ↗
