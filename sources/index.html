C / Non-Kalshi references

Standards used for the parts Kalshi does not document

Two implementation details rely on public standards rather than Kalshi documentation. They are listed here so the reasoning is auditable.

ReferenceWhere it is usedSource
RFC 8017 — PKCS #1 / PKCS #8 key encodingThe browser importer wraps the PKCS#1 RSA PEM that Kalshi generates into a PKCS#8 envelope so the Web Crypto API can import it. The key bytes themselves are never altered.RFC 8017 ↗
W3C Web Cryptography API — RSA-PSS and Ed25519Signing is performed in the browser so a private key never has to be sent to any server. Ed25519 support is detected at runtime; RSA-PSS is the portable path.Web Crypto API ↗
